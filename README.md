# RABBIT-SOFTWARE

Experimental software and research notes from RabbitSoftware. This repository is a work in progress; descriptions here are not, by themselves, evidence of a validated product, deployed system, or measured performance.

## Project status and scope

Treat sensing, biomedical, neurotechnology, networking, security, and performance concepts in this repository as unverified experiments unless a specific implementation, reproducible test, and supporting evidence are provided. Nothing in this repository is a medical device, diagnosis, treatment, or clinical recommendation.

Review code and dependencies before running them. Do not use this repository for production, safety-critical, clinical, or real-world sensing applications without independent engineering and domain review.
